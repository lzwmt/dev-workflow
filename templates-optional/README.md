# Optional templates

Not in the core pack. Add the ones your project needs:

- bug-assessment.md — read-only bug assessment (reproduction first)
- bug-test.md — same-surface verification, verdict verified/partial/failed
- bug-retro.md — why it happened, which stage missed it, same-pattern sweep
- fix-brief.md — closed-scope fix brief for a review finding
- lens-brief.md — narrow second-pass scan (stale tests, leftovers, contract shape)
- verify.md — coordinator verification notes (key path / negative case / consistency)
- handoff.md — session handoff
- project-init.md — first-run project registration checklist
- project-agents.md — per-project AGENTS.md skeleton (incl. self-verification commands)
- evidence-pack.md — how evidence files are laid out for acceptance
- issue.md — issue body format for non-local trackers
- predispatch-checklist.md — coordinator pre-dispatch self-check
