# Mini example: add a /health endpoint

One tiny feature carried through every gate, so you can see what each
artefact looks like. Read in order:

1. SPEC.md — the spec as approved
2. CHECKLIST.md — the acceptance checklist (passes scripts/checklist-lint.py)
3. FREEZE.md — produced by scripts/freeze-pkg.sh
4. REVIEW.md — the completion review report
5. DELIVERY.md — the delivery report after merge
